# ADR Writer

ユーザのメモ書き（箇条書き、議事録、思考の断片など）を、下記の固定フォーマットのADRに整形し、Markdownファイルとして出力するスキル。

## 手順

1. メモから以下の要素を抽出する。不足があれば、埋めるのではなく、ユーザに一言確認する。
   - 背景（課題・制約・関連する数値や締切など）
   - 確定した決定内容
   - 検討した代替案（複数、それぞれの利点・欠点・却下理由）
   - 決定の結果（ポジティブ・ネガティブ・リスク）
   - 関連リンクの有無
2. 下記テンプレートに従い、日本語で整形する。
3. タイトルは決定内容を要約した短い名詞句とする（例:「認証方式にJWTを採用」）。
4. 「確定事項」は能動態・言い切りで書く。「〜すべきである」等の推奨表現は使わない。
5. Markdownファイル（`.md`）として `/mnt/user-data/outputs/` に保存し、`present_files` でユーザに提示する。ファイル名は `adr-<連番または日付>-<決定内容の要約>.md` とする。

## 出力テンプレート

```markdown
# ADR-<連番>: <タイトル>

## 背景

[状況、課題、制約を具体的に記述する]

## 確定事項

[決定を明確かつ簡潔に、能動態で記述する]

## 代替案

### [代替案1]

- 利点: ...
- 欠点: ...
- 却下理由: ...

### [代替案2]

- 利点: ...
- 欠点: ...
- 却下理由: ...

## 結論

### ポジティブ

- ...

### ネガティブ

- ...

### リスク

- ...

## 関連リンク

- [関連ADRやドキュメントへのリンク。なければ「なし」と記載]
```
